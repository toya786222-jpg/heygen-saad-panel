# Frontend Only Admin Panel

This project contains only the frontend files of the admin panel, while maintaining the necessary connections to the backend.

## Structure
- `client/`: React/Vite frontend code.
- `shared/`: Shared constants and types.
- `server/routers.ts`: tRPC router types for frontend-backend communication.

## How to use
1. Install dependencies: `npm install` or `pnpm install`
2. Run development server: `npm run dev`
